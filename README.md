#PacMan AI Project
This project is based on the official UC Berkeley CS188 Project 2: Multi-Agent Search.
Project Reference: https://inst.eecs.berkeley.edu/~cs188/sp26/projects/proj2/

BTL_AI-main/

├── multiAgents.py           # Main implementation of all agents

├── game.py                  # Core game logic

├── textDisplay.py           # Terminal display
├── util.py                  # Utility functions
├── layouts/                 # Game map layouts
├── test_cases/              # Berkeley autograder test cases
└── autograder.py            # Automatic grading script
