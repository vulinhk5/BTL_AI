# PacMan AI Project

This project is based on the official UC Berkeley CS188 Project 2: Multi-Agent Search.

## Algorithms Implemented

- Reflex Agent
- Minimax Agent
- Alpha-Beta Agent
- Expectimax Agent

## Project Structure

BTL_AI-main/
├── multiAgents.py      # Main implementation of agents
├── pacman.py           # Game engine
├── game.py             # Core game logic
├── ghostAgents.py      # Ghost behaviors
├── graphicsDisplay.py  # GUI rendering
├── textDisplay.py      # Terminal display
├── util.py             # Utility functions
├── layouts/            # Game layouts
├── test_cases/         # Berkeley test cases
└── autograder.py       # Autograder
